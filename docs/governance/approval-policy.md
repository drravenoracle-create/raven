# Approval Policy

## Requires User Approval

- Official pricing.
- New fixed cost or paid contract.
- Production publication when not already approved.
- Customer data deletion.
- Destructive database changes.
- Large specification changes.
- Brand, lore, or character setting changes.
- Legal document publication.

## Agent Autonomy

Codex may autonomously research, plan, implement, test, document, and organize GitHub work when the action is reversible, low-cost, and within approved scope.
