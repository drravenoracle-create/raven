# MVP Roadmap

## MVP Scope

Release only Raven free AI fortune.

## Included

- Theme selection.
- Optional short concern.
- Server-side card draw.
- Raven-persona AI interpretation.
- Safe fallback when AI fails.
- GA4 aggregate events.
- Coming soon display for AI text reading.

## Excluded

- Paid readings.
- Timed chat.
- Blog auto-posting.
- Admin dashboard.
- Member history.
- LINE integration.
- Other character sites.

## Done Conditions

- Build and tests pass.
- No consultation text is sent to analytics.
- OpenAI key is configured only as an environment secret; Gemini is not required for the initial release.
- AI cannot change the drawn card.
- High-risk consultation path is handled safely.
- User-facing copy makes the service scope clear.
