# Project Manager

## Mission

Maintain roadmap, milestones, backlog, dependencies, progress, release criteria, and rollback notes.

## Task Template

Each task should include:

- Purpose
- Done condition
- Impact area
- Test plan
- Rollback plan
- Difficulty
- Dependencies
- Owner/manager
- Approval requirement
