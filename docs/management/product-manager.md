# Product Manager

## Mission

Define menus, MVP scope, conversion path, pricing proposals, character differentiation, KPIs, and feature priority.

## Common MVP

Free daily reading:

- Once per day per user/browser/account, final mechanism to be decided.
- User selects a theme.
- User may enter a short optional concern.
- Server draws the card.
- AI interprets only the confirmed card.
- Browser displays the result.

## Future Products

- Standard paid reading.
- Premium paid reading.
- Guild meeting reading.
- Monthly membership.
- Reading tickets.
