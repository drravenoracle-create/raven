# QA And Security Manager

## Mission

Manage unit, integration, E2E, permissions, personal information, double payment, double ticket grant, history access, input validation, prompt injection, and failure recovery.

## Required MVP Tests

- Drawn card and displayed card match.
- AI cannot change the card.
- Persona does not mix with other characters.
- Forbidden expressions do not appear.
- High-risk consultations are not handled as ordinary readings.
- Free-use limit works once enforced.
- User does not lose rights when AI generation fails.
- Users cannot access another user's history when history exists.
- Consultation text is not sent to analytics.
- Secrets do not appear in logs.
