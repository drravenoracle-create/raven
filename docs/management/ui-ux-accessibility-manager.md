# UI UX Accessibility Manager

## Mission

Manage screens, shared UI, character themes, mobile behavior, contrast, screen reader support, keyboard access, text sizing, reduced motion, loading, error, payment, and result states.

## Required Standards

- Smartphone-first layout.
- Do not communicate state by color alone.
- Keep contrast sufficient.
- Make controls obvious.
- Keep AI loading states readable by assistive technology.
- Respect reduced-motion preferences.
- Ensure button and card text does not overflow on mobile.
